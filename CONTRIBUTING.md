# Contributing to Geoguessr Archipelago

Pull requests are really appreciated, especially for everything web-related.

Feel free to talk with us on [our discord server](https://discord.gg/SdSbcqd3VY).

## Development

### Client

The client is built using [WXT](https://wxt.dev/), with only Typescript and no additional framework. Some useful commands on installation can be found [here](client/README.md).

### World

The world has to be symlinked in an Archipelago `worlds` directory. Documentation on how to work with a custom world can be found [here](https://github.com/ArchipelagoMW/Archipelago/blob/main/docs/world%20api.md). Some information can be found [here](world/geoguessr/README.md)
